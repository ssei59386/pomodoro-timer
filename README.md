# MyFitLog - フィットネス＆ライフログ PWA

筋トレ・食事メモ・睡眠・体重を日ごとに記録・可視化できる個人向けの PWA（Progressive Web App）です。
サーバー不要の完全ローカル動作で、スマホのホーム画面に追加してネイティブアプリ感覚で使用できます。

## できること

- **記録タブ**: 日付を選んで体重・睡眠（就寝〜起床から自動計算）・トレーニング（種目＋セット、直前セットのコピー、過去の種目名サジェスト）・食事メモを入力。入力すると自動保存されます。
- **カレンダータブ**: 月間カレンダーに記録のある日をドット表示。日付をタップするとその日の記録をカード表示し、そのまま記録タブへ編集ジャンプできます。
- **グラフタブ**: 過去7日間・過去30日間・全期間で体重の推移（折れ線）と睡眠時間の推移（棒グラフ）を表示。未入力日はスキップされます。
- **設定タブ**: 全データを JSON でバックアップ・復元。ホーム画面への追加方法も案内します。

## 技術スタック

- React 18 + TypeScript + Vite
- Tailwind CSS + Lucide React（アイコン）
- Recharts（グラフ）
- Dexie.js（IndexedDB ラッパー）
- date-fns（日付処理）
- vite-plugin-pwa（オフライン対応・マニフェスト生成）

## データ構造（IndexedDB）

- `dailyLogs`: 日付（`YYYY-MM-DD`）をキーに、体重・睡眠・食事・トレーニングを保持
- `exerciseHistory`: 過去に入力した種目名とサジェスト用の最終使用日時

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド
npm run test     # ユニットテスト（Vitest）
```

## データについて

すべてのデータは端末内（IndexedDB）にのみ保存され、外部サーバーへの送信は一切行いません。
機種変更やブラウザデータ削除の前には、設定タブのバックアップ機能で必ずデータを書き出してください。
